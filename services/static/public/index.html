Details

What this page proves

The kernel resolves the canonical service path, selects Worker capacity in a compatible sandbox, and streams each response from a sandboxed Deno Worker.

HTML, CSS, JavaScript, and SVG files are read from the package's read-only mount and returned with explicit content types.
Only known public assets are exposed. Unknown asset paths return 404 and cannot traverse the package filesystem.
Local JavaScript drives sliders, status feedback, theme switching, notifications, and accessible accordion state.
